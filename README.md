# Christian Abasilikwu · PrimeEdge Systems

Voice and WhatsApp agents that answer every enquiry and book appointments, invoice and payment follow-up, lead qualification and reporting.

Every build has error handling, retries and alerts, so if something breaks the owner hears about it straight away.

- AI voice receptionist for an HVAC company (Vapi + n8n), books real calendar visits and flags gas emergencies
- Invoice system that sends, tracks and chases payments through Stripe
- WhatsApp support agent that answers from a company's product docs
- Shopify abandoned checkout emails that stop when the customer buys

**Tools I use most:** n8n, Vapi, OpenAI, Airtable, Supabase, Stripe, Google Workspace, Slack
